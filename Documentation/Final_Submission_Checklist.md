# Final Submission Checklist

## Project files
- [ ] Final narrated MP4 is present and checked.
- [ ] MP4 is 16:9, 1920×1080, H.264 and shorter than 7 minutes.
- [ ] Opening frame shows title, concept, student name and ID.
- [ ] Closing frame shows summary, references and AI disclosure.
- [ ] Complete source code and editable files are included.
- [ ] Storyboard and mathematical verification documents are included.
- [ ] Narration script, references, AI disclosure and viva notes are included.

## GitHub
- [ ] Repository visibility is Public.
- [ ] Source files and documentation are pushed.
- [ ] Binary MP4, WAV and PDF assets are uploaded or linked separately.
- [ ] Open the repository in an incognito/private browser window to check access.

## Final submission
- [ ] Check the instructor’s submission instructions and official form.
- [ ] Submit the public repository URL before the stated deadline.
