# Video Deliverables

The rendered MP4 assets are included in the separately supplied project ZIP:

- `Video/Gradient_Animation_Final.mp4` — final narrated 1080p video
- `Video/Gradient_Visual_Track_1080p.mp4` — silent retimed visual track
- `Video/Gradient_Visual_Draft_1080p.mp4` — original silent visual draft

These binary files have not been committed to this GitHub repository because the connected GitHub file actions only expose UTF-8 text file creation and do not provide a binary upload operation. The ZIP download contains the MP4 files and the generated WAV audio.
